# Фокусне питання та каталог відношень концептуальної карти
**Предметна область:** Автоматизація виробничих процесів (Промисловість: верстати ЧПК, SCADA, ПЛК).

---

## 1. Фокусне питання (Focus Question)
> **«Як взаємодіють компоненти апаратного рівня верстатів ЧПК із програмним забезпеченням SCADA та системами безпеки для забезпечення безперервного і безпечного виробничого циклу?»**

---

## 2. Каталог відношень (8-12 типів)
| Тип відношення | Визначення | Приклад використання |
| :--- | :--- | :--- |
| **is-a** | Відношення ієрархії, де підпоняття є видом загального поняття. | Верстат ЧПК *is-a* Обладнання |
| **part-of** | Відношення композиції, де компонент є складовою частиною цілого. | Шпиндель *part-of* Верстат ЧПК |
| **controls** | Управління або регулювання одного об'єкта іншим. | ПЛК *controls* Гідростанція |
| **monitors** | Відстеження параметрів чи стану об'єкта в реальному часі. | SCADA *monitors* Датчик температури |
| **triggers** | Виникнення події, що запускає певну дію чи реакцію системи. | Перевищення температури *triggers* Аварійне блокування |
| **processed-by** | Обробка матеріалу або даних за допомогою певного механізму. | Металева заготовка *processed-by* Шпиндель |
| **regulated-by** | Дотримання встановлених норм, стандартів чи регламентів. | Калібрування *regulated-by* Стандарт IEC 60751 |
| **communicates-via** | Передача даних або команд через конкретний протокол чи шину. | ПЛК *communicates-via* Протокол Modbus TCP |
| **protects** | Запобігання аваріям або захист персоналу й обладнання. | Аварійна кнопка E-Stop *protects* Електрообладнання |

## 4. Покриття компетентнісних питань (CQ з ЛР 4)
Карта безпосередньо покриває такі CQ:
- **CQ-01:** Порядок дій при критичній аварії у SCADA.
- **CQ-03:** Причини аварійної зупинки шпинделя при нагріванні.
- **CQ-07:** Перевірка параметрів перед щозмінним запуском ЧПК.
- **CQ-10:** Вплив падіння витрати ЗОР на роботу шпинделя.
- **CQ-15:** Цілісність конфігурацій ПЛК та логування.
