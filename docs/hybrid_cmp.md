# Гібридний пошук та Reranking

## 1. Архітектура гібридного пошуку
Для підвищення точності та повноти пошуку в доменній області промислової автоматизації реалізовано двоступеневу архітектуру:
1. **Перший етап (Retrieval):** Комбінування лексичного пошуку (**BM25**) та семантичного векторного пошуку (**FAISS HNSW**) за допомогою алгоритму ранжування **RRF (Reciprocal Rank Fusion)** з параметром $k=60$.
2. **Другий етап (Reranking):** Переранжування кандидатів за допомогою крос-енкодерної моделі `BAAI/bge-reranker-base` для точної оцінки семантичної близькості запиту і знайдених фрагментів.

## 2. Результати тестування продуктивності та затримки (Latency)

| Тестовий запит | Метод пошуку | Середня затримка (Latency, мс) | Опис результату / Топ-фрагмент |
| :--- | :--- | :--- | :--- |
| **вимоги до верстатів ЧПК та шпинделя** | Hybrid + Rerank | **474.62 мс** | Успішно знайдено технічні регламенти шпинделів за стандартом IEC |
| **безпека роботи програмованих контролерів ПЛК** | Hybrid + Rerank | **459.70 мс** | Знайдено вимоги до систем керування згідно з IEC 61131-3 |
| **стандарти електрообладнання машин IEC** | Hybrid + Rerank | **445.72 мс** | Ідентифіковано положення щодо електробезпеки (IEC 60204-1) |

## 3. Аналіз ефективності
* Завдяки поєднанню BM25 та векторного пошуку система стабільно знаходить точні збіги ключових термінів (наприклад, абревіатур ЧПК, ПЛК, найменувань стандартів IEC), які іноді можуть губитися при чистому семантичному пошуку.
* Крос-енкодерний реранкер забезпечує високу релевантність перших позицій, при цьому загальна затримка виконання запиту (`~445-474 мс`) залишається в прийнятних межах для інтерактивних систем.

## 4. Висновок
Впровадження гібридного пошуку у зв'язці з реранжуванням значно покращило якість видачі технічної документації порівняно з чистим векторним пошуком, забезпечивши максимальну точність знаходження нормативних вимог.
