# Звіт експертної сесії та метрики надійності LLM

## 1. Обчислення метричних показників
Для обчислення каппи Коена ($\kappa$) використано формулу:
$$\kappa = \frac{P_o - P_e}{1 - P_e}$$
де $P_o$ — відсоток узгоджених відповідей між Моделлю А та Моделлю B, а $P_e$ — ймовірність випадкового збігу.

* **Загальна кількість тверджень:** 30
* **Частка підтверджених (Verified):** $24 / 30 = 80.0\%$
* **Частка відхилених (Rejected):** $5 / 30 = 16.7\%$
* **Частка в очікуванні (Pending):** $1 / 30 = 3.3\%$
* **Коефіцієнт узгодженості Коена ($\kappa$):** $0.82$ (високий рівень згоди між GPT-4o та Claude 3.5 Sonnet).
* **Середній час верифікації одного твердження:** 2.4 хвилини.

## 3. Розподіл та класифікація помилок
1. **Галюцинації (40% помилок):** Вигадування термінів та передчасних технологій (CLM-005, CLM-009).
2. **Порушення регламентів безпеки (40% помилок):** Некоректні права доступу операторів (CLM-024).
3. **Маркетингові перебільшення (20% помилок):** Заяви про 100% заміну вимірювань цифровими двійниками (CLM-020).

## 4. Політика прийняття знань (Knowledge Acceptance Policy)
1. **Правило 1 (Швидке прийняття фактів):** Технічні характеристики із джерелами V1 та confidence $\ge 0.95$ приймаються автоматично після виконання Python-лінтера.
2. **Правило 2 (Подвійна верифікація правил безпеки):** Усі правила, що стосуються аварійних зупинок (E-Stop, інтерлоки), обов'язково проходять CoVe та експерта-людину.
3. **Правило 3 (Відхилення необґрунтованих гіпотез):** Гіпотези без діючих міжнародних стандартів (ISO/IEC) автоматично відхиляються.
