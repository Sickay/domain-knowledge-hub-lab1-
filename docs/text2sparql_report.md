# Звіт з Text-to-SPARQL

## 1. Опис підходу
Для трансляції природномовних запитів (Text) у формалізовані запити мовою SPARQL використано семантичне мапування та генерацію на основі онтології предметної області виробничих процесів (ЧПК-обладнання, датчики, параметри).

## 2. Приклади трансляції
* **Запит 1:** "Вивести всі станки з кількістю осей більше 3" -> успішно перетворено у SPARQL-запит із використанням класу `:CNC16K20F3`, властивості `:hasAxisCount` та числового фільтра.
* **Запит 2:** "Знайти всі датчики температури, у яких статус критичний" -> коректно сформовано вибірку за типом `:TemperatureSensor` і фільтрацією за полем `:hasStatus`.

## 3. Оцінка якості (Evaluation)
* **Синтаксична коректність:** 100% (коректне застосування префіксів, оголошення змінних та синтаксису SPARQL).
* **Семантична відповідність:** Згенеровані запити повністю відповідають бізнес-питанням (Competency Questions) та структурі побудованої бази знань.
