# Порівняння моделей Embeddings

## 1. Обрані моделі для порівняння
1. **Основна мультимовна модель:** `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` (оптимізована для багатомовного семантичного пошуку з якісною підтримкою української мови).
2. **Базова модель:** `sentence-transformers/all-MiniLM-L6-v2` (компактна модель загального призначення для порівняння швидкодії).

## 2. Параметри векторного індексу FAISS (HNSW)
* **Тип індексу:** `IndexHNSWFlat`
* **Метрика відстані:** Euclidean / L2 distance
* **Розмір графа (`M`):** 32
* **Глибина пошуку (`efSearch`):** 64
* **Обсяг індексованого корпусу:** 210 фрагментів (`data/corpus.jsonl`)

## 3. Таблиця порівняльних результатів вимірювань

| Модель Embeddings | Час побудови індексу (210 чанків) | Recall@5 (на 20 запитах) | Середня затримка пошуку (latency) | Підтримка української мови |
| :--- | :--- | :--- | :--- | :--- |
| **1. paraphrase-multilingual-MiniLM-L12-v2** | **9.01 сек** | **0.89** | **34.93 мс** | Рідна (висока якість) |
| **2. all-MiniLM-L6-v2** | **15.90 сек** | 0.72 | **24.97 мс** | Обмежена (базова) |

> **Аналіз результатів:**
> * Модель `paraphrase-multilingual-MiniLM-L12-v2` демонструє швидшу побудову індексу (9.01 сек проти 15.90 сек для `all-MiniLM-L6-v2`) та забезпечує вищу точність семантичного пошуку завдяки повноцінній підтримці багатомовного словника.
> * Модель `all-MiniLM-L6-v2` показує дещо меншу затримку пошуку (24.97 мс), проте програє за часом індексації та якістю розуміння українськомовної технічної термінології.

## 4. Перевірка динамічного оновлення (Upsert / Delete)
1. **Операція Upsert:** Успішно додано 5 нових тестових документів (`test_f1` — `test_f5`) безпосередньо до активного індексу FAISS.
2. **Операція Delete:** Фрагмент `test_f1` успішно вилучено з масиву метаданих сховища.

## 5. Висновок
Для розробки системи семантичного пошуку в доменній області промислової автоматизації обрано модель `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`, оскільки вона забезпечує кращу якість релевантності та ефективну обробку української технічної документації.
