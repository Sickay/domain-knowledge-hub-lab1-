# Опис виробничих ситуацій 
## Ситуація 1: Нормальний режим роботи верстата
* **Об'єкт:** Верстат `:CNC_01` та контролер `:PLC_01`.
* **Стан:** Верстат функціонує в штатному режимі.
* **Атрибути:** 
  * `hasStatus`: "active"
  * `hasTemp`: 68.5 °C (у межах допустимої норми)
  * `hasPressure`: 0.55 МПа
* **Опис:** Система моніторингу фіксує нормальні показники датчиків, аварійних сигналів немає, ПЛК керує процесом без зауважень.

## Ситуація 2: Аварійний перегрів шпинделя
* **Об'єкт:** Шпиндель `:Spindle_02` та датчик температури `:TS_04`.
* **Стан:** Аварійний (перевищення температурного порогу).
* **Атрибути:**
  * `hasStatus`: "overheated"
  * `hasTemp`: 82.4 °C (вище критичного рівня 75 °C)
* **Опис:** Раузер HermiT автоматично класифікує обладнання у стан підвищеної температури завдяки логічним правилам, що вимагає зупинки лінії або втручання системи безпеки.

## Ситуація 3: Зниження тиску в гідросистемі
* **Об'єкт:** Датчик тиску `:PS_02`.
* **Стан:** Попередження (низький тиск).
* **Атрибути:**
  * `hasStatus`: "low_pressure"
  * `hasPressure`: 0.42 МПа
* **Опис:** Датчик сигналізує про відхилення робочого тиску від номінального значення, що фіксується онтологією для подальшого реагування.
