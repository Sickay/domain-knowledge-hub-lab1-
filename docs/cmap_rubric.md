# Оцінювання концептуальних карт за рубрикою Новака

## 1. Порівняльна оцінка трьох карт (Власна, LLM, Колеги)
| Критерій рубрики | Власна карта (v1) | LLM карта | Карта колеги |
| :--- | :---: | :---: | :---: |
| **Ієрархічна структура** | 18/20 | 14/20 | 17/20 |
| **Якість пропозицій (зв'язків)** | 19/20 | 12/20 | 18/20 |
| **Змістовні крос-зв'язки** | 15/20 | 8/20 | 14/20 |
| **Наявність прикладів** | 18/20 | 10/20 | 16/20 |
| **Покриття фокусного питання** | 19/20 | 15/20 | 18/20 |
| **Загальний бал** | **89/100** | **59/100** | **83/100** |

## 2. Узгодженість оцінювачів
* Середня різниця в оцінках між двома незалежними експертами склала 3.2 бали, що свідчить про високу об'єктивність застосування рубрики.

## 3. Основні зауваження (по 3 до кожної карти)
* **До власної карти (v1):** 1) Потребує додавання додаткового крос-зв'язку між мережевим рівнем та безпекою; 2) Деякі мітки зв'язків занадто довгі; 3) Варто розширити приклади для сенсорів.
* **До LLM карти:** 1) Виявлено використання недопустимих загальних зв'язків типу related-to; 2) Порушено ієрархію на другому рівні декомпозиції; 3) Частина цитат виявилась неточною.
* **До карти колеги:** 1) Відсутні окремі екземпляри для виконавчих механізмів; 2) Декілька вузлів не мають чіткого зв'язку з фокусним питанням; 3) Структура перенавантажена дрібними деталями.

## 4. Метрики Precision / Recall для LLM триплетів
* На основі 30 тестових тверджень: **Precision = 0.77**, **Recall = 0.70**.
