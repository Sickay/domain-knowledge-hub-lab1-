# Протокол застосування Chain-of-Verification (CoVe)

## 1. Твердження CLM-005 (Нейроморфні контролери до 2027 року)
* **Базовий вихід Моделі А:** "Нейроморфні чипи повністю замінять стандартні ПЛК на заводах до 2027 року."
* **Перевірочні запитання (CoVe questions):**
  1. Які існують чинні стандарти сертифікації нейроморфних чипів для АСКТП?
  2. Скільки часу займає цикл сертифікації за стандартом IEC 61508?
* **Незалежні відповіді моделі:** "Наразі сертифікованих промислових чипів такого типу немає; цикл сертифікації за IEC 61508 триває від 3 до 5 років."
* **Рішення:** Твердження є нереалістичним за часовими рамками та **відхилено**.

## 2. Твердження CLM-024 (Скидання критичних аварій оператором)
* **Базовий вихід Моделі А:** "Оператор має право самостійно скидати будь-які аварії для економії часу."
* **Перевірочні запитання:**
  1. Що вимагає ISO 13849 щодо усунення причин аварій перед їх скиданням?
  2. Хто несе відповідальність за повторний пуск неперевіреного обладнання?
* **Незалежні відповіді моделі:** "Стандарти безпеки забороняють скидання критичних блокувань без усунення фізичної причини інженером."
* **Рішення:** Твердження визнано небезпечним і **відхилено**.
