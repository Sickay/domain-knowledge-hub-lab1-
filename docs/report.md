# Звіт до Лабораторної роботи №2
**Предметна область:** Автоматизація виробничих процесів (Промисловість)  
**Гілка:** `lab02`

---

## Результат 1: Реєстр джерел знань (`docs/sources.csv`)
Сформовано реєстр із 10 ключових джерел виробничих знань (паспорти верстатів ЧПК, журнали SCADA, бази тікетів, дані телеметрії тощо). Усі поля з комами коректно взято в подвійні лапки для забезпечення валідності CSV-формату.

## Результат 2: Архітектура мінімального KMS (`docs/architecture.png`)
Розроблено схему шарової архітектури мінімальної системи управління знаннями підприємства (6 шарів та 5 наскрізних функцій безпеки, якості, походження, версіонування та метрик), а також додано таблицю компонентів і ризиків.

## Результат 3: Порівняння платформ (`docs/platform_comparison.csv`)
Проведено порівняльний аналіз трьох платформ (Confluence, Obsidian, Notion) за 8 критеріями з урахуванням LLM-готовності та перевіркою маркетингових тверджень постачальників. За результатами розрахунків рекомендовано використання платформи Notion / гібридного Markdown-підходу.

## Результат 4: Репозиторій знань за принципом *docs-as-code* (`kb/*.md`)
Створено базу знань у форматі Markdown ізYAML Front Matter метаданими, написан автоматизований Python-лінтер (`tools/lint_meta.py`) для перевірки структури, версій SemVer, дат і рівнів чутності, а також налаштовано GitHub Actions CI для автоматичного запуску перевірок при кожному коміті.
