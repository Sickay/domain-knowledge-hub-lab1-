# domain-knowledge-hub-lab1-
## Таблиця шарів та компонентів мінімального KMS

| Шар | Компонент | Технологія | Власник | Ризик |
| :--- | :--- | :--- | :--- | :--- |
| **1. Джерела (Sources)** | Бази даних SCADA, PDF-паспорти, чати | SQL, PDF, Telegram | Головний інженер / Наладчики | Нестандартизовані формати, втрата неявних знань |
| **2. Захоплення (Ingestion)** | Коннектори та імпортери | Python scripts, Webhooks, API | Інженер з автоматизації | Зрив синхронізації при зміні структур джерел |
| **3. Опрацювання (Processing)** | Лінтери, валідація, структурація | Python 3.11, Pandas, Pydantic | Data Engineer | Помилки автоматичної валідації метаданих |
| **4. Сховища (Storage)** | Репозиторій знань та векторна база | Git, Markdown, ChromaDB | Knowledge Manager | Пошкодження історії комітів або дублювання ID |
| **5. Сервіси (Services)** | LLM-аудитор, пошук, API | OpenAI API / GPT-4o, LangChain | Архітектор систем | Галюцинації моделі або застарілі дані |
| **6. Інтерфейси (Interfaces)** | Web UI, Confluence, Dashboard | GitHub Preview, Streamlit | Користувачі / Оператори цеху | Низька залученість персоналу цеху до внесення знань |
