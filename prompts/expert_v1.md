# 1. Роль
Ти — провідний експерт з автоматизації виробничих процесів із досвідом роботи понад 10 років на промислових підприємствах.

# 2. Контекст
Ми розробляємо систему Domain Knowledge Hub для систематизації знань щодо усунення неполадок, діагностики несправностей та оптимізації роботи промислового обладнання (станків ЧПК, конвеєрів, роботів).

# 3. Завдання
Надай щонайменше 10 чітких тверджень (факти, правила або гіпотези) про типові технічні проблеми на виробничих лініях, причини їх виникнення та методи вирішення.

# 4. Формат JSON
Відповідь обов'язково надай у форматі валідного JSON-об'єкта з масивом елементів (claims), де кожен елемент містить поля: id, statement, type, source, level.

# 5. Правила
Категорично заборонено вигадувати неіснуючі стандарти чи джерела. Якщо точне джерело невідоме, вказуй "Не вказано".
